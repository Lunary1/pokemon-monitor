## Review notes

- This table is a living artifact, not a one-time snapshot — re-check each row against the actual code (not memory of a prior review) at every retro (`docs/SDLC.md` §12).
- Several rows above are weaker than plan §15 implies because the plan describes the *intended* end state, not what has shipped so far. Treat "Partially mitigated" / "Not implemented" rows as backlog candidates, not as accepted risk, until the missing half actually lands.
- When a mitigation ships (e.g., `robots.txt` enforcement, the notification cooldown, the `/api/health` route, the retention purge), update the corresponding row's Status and Last reviewed columns in the same PR that lands the fix — don't let this file drift from reality again.
